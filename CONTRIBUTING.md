# Правила работы с репозиторием

| Элемент | Правило | Пример |
| --- | --- | --- |
| Ветка | `feature/<номер Issue>-<краткое-описание-латиницей>`, создаётся от актуального `main` | `feature/7-station-zhlobin` |
| Коммит | Conventional Commits со ссылкой на Issue: `тип(область): описание (#N)`; типы — `feat`, `fix`, `test`, `docs`, `refactor` | `feat(registry): добавить станцию Жлобин (#7)` |
| Pull request | один PR на один Issue, описание по шаблону, строка `Closes #N` | `Closes #7` |
| Рецензент | назначается по таблице в `README.md` | вариант 5 → рецензент — вариант 6 |
| Слияние | выполняет автор PR после одобрения рецензента и успешной проверки CI | Merge pull request |

Запрещается:

- отправлять изменения непосредственно в `main`;
- изменять чужие ветки;
- удалять чужие станции, направления, методы и тесты при разрешении конфликтов.

Новые станции, направления, методы и тесты добавляются **в конец** соответствующего списка или класса.
