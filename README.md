# Справочник станций Гомельского отделения Белорусской железной дороги

Учебный проект по дисциплине «Средства и технологии анализа и разработки информационных систем».
Лабораторная работа «Командная разработка в Git по модели GitHub Flow».

## Сборка

```bash
mvn verify
```

Требуется JDK 21 и Maven 3.9+.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `src/main/java/.../Station.java` | запись о станции |
| `src/main/java/.../Line.java` | железнодорожные направления |
| `src/main/java/.../StationType.java` | типы станций |
| `src/main/java/.../StationRegistry.java` | справочник станций и методы поиска |
| `STATIONS.md` | таблица станций (проверяется тестом `StationsDocTest`) |
| `CONTRIBUTING.md` | правила работы с репозиторием |
